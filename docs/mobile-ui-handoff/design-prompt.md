# 复制给设计 AI 的指令

你是负责中文移动端产品的资深 UI/UX 设计师。请为 Daily Ledger 重新设计移动端界面。我会提供 `design-brief.md` 与 `ui-manifest.json`，请先读取它们。

这是一个个人本地账本 Web 应用，包括「生活预算」与「铜钱生意」。生活预算的重点是本周还能花多少、快速记支出、理解收入分配和资金流向；生意模块的重点是销售/进货记录、现金库、库存成本和经营情况。

请把文件中的页面组成视为现有功能契约，把现有颜色与布局视为可修改的参考。你可以重排信息架构、改导航形式、将内联表单改为弹层/子页，并充分发挥审美。请先选定明确视觉方向，说明如何服务本产品，再进行设计。

必须满足：

1. 保留两个模块的完整功能，资金池互相独立。
2. 明确区分本周剩余、周期日常剩余、可动用余额、储备金和总金额。
3. 保留提前支付的付款日期/归属日期、固定预留、系统结转、资金缺口、历史记录缺数据等状态。
4. 铜钱待确认销售已经影响资金库存；确认只改状态；取消回滚；库存显示成本；利润允许为负。
5. 保留本地保存说明、整站 JSON 备份与模块 Excel 备份，并明确恢复覆盖范围。
6. 不擅自加入登录、云同步、银行连接或未经要求的新业务。
7. 使用中文真实文案；自拟账目注明演示数据，并检查金额关系。
8. 支持亮色/暗色、360–430px手机宽度、底部安全区和输入键盘。

第一轮请交付四个关键视图：

- 生活预算首页：首屏明确本周可花，记支出容易找到。
- 记支出：普通状态与开启未来开销后的状态。
- 资金流向详情：明确来源/去向和「原余额 ± 变化 = 新余额」，同时给出旧记录缺快照的降级状态。
- 铜钱生意首页：资产、两库、记销售/进货、趋势、流水；提供待确认行样式。

同时提供：

- 页面/弹层导航关系，以及其余功能的位置映射。
- 设计 tokens：色值、中文/数字字体、字号、间距、圆角、边框、图标、动效。
- 组件清单与关键状态：金额主卡、快捷入口、口袋余额、事件行、类别选择、表单、确认弹窗、图表、空状态。
- 如果你支持可视化输出，请提供可查看的高保真稿或交互原型，而不只写风格形容词。
- 如果输出代码，请用 React + TypeScript 和可复用组件，使用演示数据，先完成视觉原型；业务计算保留为接口，不自行重写现有预算算法。

请逐项说明功能如何映射到新设计。审美自由，业务含义要准确。
