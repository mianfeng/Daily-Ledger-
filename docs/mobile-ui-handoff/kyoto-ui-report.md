# 竹青宣纸 UI 与交互升级

日期：2026-10-16。实施基线：`bf84e20`。依据用户提供的 `daily-ledger-codex-handoff.zip` 中 v2.1 规范实施。交接包中的提示词与原型脚本作为参考材料；执行、提交和推送范围来自用户的本次明确授权。

## 完成内容

- **视觉**：宣纸白底、纯白卡片、竹青生活色、赤陶生意色、20px圆角和1px细边框；移除原主控件厚重拟物阴影，保留亮暗两套主题。
- **外壳**：生活/生意同时挂载，通过 hidden 和 aria-hidden 切换；各自草稿、筛选状态和滚动位置保留；隐藏模块不挂载弹层。
- **弹层**：明确声明 variant/footer；顶部下拖超过90px关闭；浏览器返回关闭最上层窗口；有输入时继续确认放弃；保留焦点限制、恢复和 visualViewport 避让。
- **备份**：记录独立的最近导出时间元数据；超过7天或从未导出时显示提醒；JSON/Excel先解析、再展示记录数/最新日期差异；旧备份提示风险，并可先导出当前整站快照再恢复。
- **金额**：四个主要记账金额字段支持加减算式、结果徽章、失焦规约和 +10/+50/+100/−5 筹码；以受限十进制解析器求值，无 eval。
- **生活首页**：本周与周期双层主卡、操作台、直接可读的状态指标、带 W 周次与金额的时间轴；支出日期/备注并排，并显示扣款后剩余预览条。
- **历史与详情**：缓冲/储备、提前支付、大额/计划外筛选与关键词搜索；先点更多再确认回滚；真实分配按瀑布层级展示，旧记录和缺口降级保持。
- **生意**：资产恒等式与两库拆解合并展示；比例滑块、数字框和预设联动保证100%；销售成本旁显示毛利、毛利率与按当前比例计算的利润分配，超过库存立即报错并禁用提交。

主要代码文件：`App.tsx`、`components/DailyLedger.tsx`、`components/CopperShop.tsx`、`components/ui/Ui.tsx`、新增的 `Backup.tsx`、`SmartMoneyInput.tsx`、`RatioSplitControl.tsx`、`money.ts`、`overlayHistory.ts`，以及 `index.css`。

## 兼容适配

1. 大额支出仍按现有缓冲金与周期日常资金规则处理，未照搬参考稿中不准确的「缓冲/储备」文案。
2. 提前支付筛选使用实际字段 `expenseTiming === 'prepaid'`，不新增不存在的 isPrepaid 数据字段。
3. 可选跨模块分红桥接未加入；预填生活收入并不等于生意资金已扣减，不引入会被误解为真实转账的入口。
4. 全部日常 Overlay 调用显式化；保留旧内部 icon/layer 参数兼容，不再依赖中文标题或 children 扫描决定容器与页脚。
5. 返回栈采用一层共享哨兵管理嵌套窗口，避免两个窗口同批关闭后残留历史项；返回键能逐层关闭，前进键不重建已关闭表单。
6. 亮色警告/盈利/危险文字与暗色危险文字略调深浅以满足小字对比度；RGBA浅底按实际表面合成后检测。
7. 字体使用给定本地字体栈与现有 Noto Sans SC 加载方式，没有新增远程字体依赖。
8. 新增 `daily_ledger_last_backup_at` **只作备份提醒元数据**，不进入账本模型或备份内容；既有两模块账本键与主题键不变。
