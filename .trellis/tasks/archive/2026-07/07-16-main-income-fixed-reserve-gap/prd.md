# 主要收入补足固定预留缺口

## Goal

主要收入到账时先补足固定支出预留缺口，而不是只在固定预留为 0 时才预留。

## Problem

当前规则是 `fixedReserved > 0` 时主要收入不再新增固定预留。这样如果固定支出总额为 3429、当前固定预留为 1000，下次主要收入不会补剩余 2429，固定支出预留会不足。

## Requirements

* 固定预留目标等于 active 固定支出清单总额。
* 固定预留缺口等于 `max(0, 固定预留目标 - 当前固定预留)`。
* 主要收入优先补固定预留缺口，再进入储备、最低每周生活线、缓冲和周预算分配。
* 当前周期内追加主要收入也应先补固定预留缺口。
* UI 提示必须说明“补足缺口”，不能再写“已有固定预留不会重复新增”。

## Acceptance Criteria

* [x] 固定支出总额 3429、当前固定预留 1000、主要收入 20000 时，新增固定预留为 2429。
* [x] 固定支出总额 3429、当前固定预留 3429、主要收入到账时，不再新增固定预留。
* [x] 固定支出总额 3429、当前固定预留 1000、主要收入 1000 时，新增固定预留为 1000。
* [x] 当前周期内追加主要收入也先补固定预留缺口。
* [x] 收入面板和固定支出面板提示改为“补足缺口”。
* [x] `npm run build` passes.

## Technical Approach

* 在 `allocateIncome` 中使用固定预留缺口计算本次 `fixed` allocation。
* 对当前周期追加主要收入路径也应用同样缺口规则。
* 更新 `DailyLedger` 的确认提示和说明文字。
* 更新 state-management 规范中的固定预留规则。
